# Finger-relay drill (2026-08-03)

Same-direction ratcheting: one rotation direction per episode, every goal a
fixed 0.6 rad further (screwdriver accumulation).  A single stroke tops out
~1.4 rad, so continuing REQUIRES finger relay (release, re-place, roll on).
84_relay_drill_s39 (real physics, arm locked, warm from the hold-and-roll
policy): fleet average 2.7 goals (~1.6 rad) with grasped 92%; best episodes
run 5-7 consecutive goals = 3.0-4.2 rad (240 deg) of continuous relayed
rotation.  Consistency, not capability, is the remaining gap -- the phase-
memory hypothesis for a future obs upgrade.
